# 🎮 Shoot Me Up

Projet C# réalisé dans le cadre du **module P320** à l'ETML.

L'objectif du projet est de mettre en pratique la programmation orientée objet à travers la création d'un jeu structuré, lisible et évolutif.

## ✨ Points clés

- Développement en **C# / .NET**
- Séparation du projet en dossiers **Model**, **View** et **Helpers**
- Gestion des ressources de l'application
- Mise en pratique de la programmation orientée objet
- Solution Visual Studio prête à être explorée

## 🗂️ Structure du dépôt

- `ShootMeUp/ShootMeUp.sln` : solution Visual Studio
- `ShootMeUp/ShootMeUp/Model` : logique et données du jeu
- `ShootMeUp/ShootMeUp/View` : affichage et interface
- `ShootMeUp/ShootMeUp/Resources` : ressources du projet
- `doc` : documentation
- `assets` : éléments visuels du dépôt

## 🚀 Lancer le projet

1. Clone le dépôt :

   ```bash
   git clone https://github.com/Pt74bsx/320_shootMeUp.git
   ```

2. Ouvre `ShootMeUp/ShootMeUp.sln` dans Visual Studio.
3. Restaure les dépendances si Visual Studio le demande.
4. Compile puis lance le projet.
